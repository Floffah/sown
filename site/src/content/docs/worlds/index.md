A world is an interactive environment. A project contains the source files, world definitions, scenes, scripts, and assets used to construct it. One project can describe multiple worlds.

Start with the [project layout](/worlds/project/), then define a [world file](/worlds/world-file/) and its [nodes and geometry](/worlds/nodes/).

Use [behaviour references](/worlds/behaviours/) to attach scripts to nodes. Read [source distribution](/worlds/distribution/) for how servers advertise the repository and revision clients retrieve.

The examples use the Minimal Room project included with Sown. World files are JSON, even when their filenames use `.world` or `.scene`.
